# 执行与验收

1. Linux DNS/ingress：补请求完成及专属链路清理，保留失败阻止重接；真实 resolved 与取消/迟到回复测试。
2. TopSAP：官方证据文档、Linux 身份与窄范围 helper、独立向量/原生对照、扩展跨平台适配器模拟测试。
3. headless：本地 controller、代际隔离/异步 upstream 退休、显式 TUN/代理选项与权限、状态/清理测试及系统烟雾脚本。
4. GUI：接通 Linux TUN 管理器和共享热切换；更新 Linux 配置导入测试，验证授权失败保存回滚、代理保留及系统端到端流程。
5. 汇总规范和使用说明；每次改文件后仅提交所属修改。并行协作者不得覆盖他人工作。
6. 本地 root/nested Go test/vet、前端测试、Linux 可编译部分交叉编译；GitHub Linux 隔离系统验证，处理实际失败。
7. 同一最终源码提交四端 Actions 全部成功后下载六个产物，校验架构/权限/哈希并发布新预览 Release，验证匿名下载。

关键风险：gVisor 同步重连回调锁重入、取消后的 DBus 迟到执行、Linux 设备身份权限、跨附件旧策略结果。回归测试要驱动真实交错，不能仅检查函数被调用。若 CI 揭示行为缺陷，修复其归属模块后重新验证；不禁用失败测试或伪造设备身份。
