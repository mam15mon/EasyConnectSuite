# 设计

色板：画布 #F4F6FA、面板 #FFFFFF、文字 #172B4D、主操作 #2459C4、在线 #157347、错误 #B42332；连接中 #9A6400。Segoe UI Variable / Microsoft YaHei UI 用于中文界面，地址与时长保持等宽数字。列表行以分隔线组织，不给每条连接单独加阴影卡片。

布局：顶栏品牌 + 全局汇总 + 新建；主体上半部为全宽连接列表，下半部左边为选中连接详情、右边为选中连接资源，底部托盘与日志提示。全部左对齐。连接列表提供直接操作，详情按钮同样作用于选中 profileId。当前选择以蓝色行侧边和名称区分，在线状态另用绿点+文字，不混用颜色含义。

```
品牌 / VPN 工作台             已连接 / 连接中             新建 VPN
全部连接                     筛选：全部 / 在线         断开全部
名称与协议 | 网关 | 状态和时长 | 模式 | 连接/断开 / 查看
当前查看：名称 / 状态           名称的授权资源 / 搜索 / 刷新
IP / DNS / 本地代理            IP资源 / 域名资源
模式设置 / 编辑 / 删除
托盘行为 / 日志目录
```

评审：不使用单连接大按钮作为首页焦点；多连接行和各自操作是主入口。统计采用紧凑文字而非装饰大数字，资源始终标明归属。预览使用文档地址和示例域名，展示至少两条在线、一条未连接、一条错误，且可模拟操作。

数据：vpn-connections 更新列表/全局统计；vpn-status 按 ID 同步该行且仅更新选中详情；status-tick 更新该行时长；vpn-resources 和异步 GetVPNResources 按捕获的选中 ID 校验。SetActiveProfile 后再读取选中详情，并用选择序号丢弃过期结果。行操作在任何 await 前捕获 ID，不先切换选中项来操作其他 VPN。
