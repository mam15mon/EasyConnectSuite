# 双栏设计与日志边界

用户选择：左侧连接列表，右侧详情工作区。色板：底色 #F6F7F9、主工作面 #FFFFFF、文字 #202938、灰字 #788394、蓝 #315EEA、绿 #23845B。Segoe UI Variable / Microsoft YaHei UI；名称 22px、正文 13px、辅助 11px，地址使用等宽数字。无装饰渐变或面板阴影。

```
VPN 工作台                                  全局在线计数
连接  + 新建             当前名称                       连接/断开
全部 / 运行中            协议 / 网关           状态 / 时长
名称        连接按钮      虚拟IP | DNS | SOCKS | HTTP
协议 / 状态 / 时长       授权资源 | 连接设置 | 运行记录
名称        断开按钮      搜索与资源内容 / 模式设置 / 生命周期日志
名称        取消按钮
断开全部 / 日志目录
```

左栏 280px，淡灰底，选中项白底与蓝边；每项只保留一个独立生命周期操作，名称即查看，无重复“查看”按钮。右边白色工作区直接组织内容，用分隔线代替两块并排大卡片。状态颜色和选择颜色独立。

评审：第一版全宽表格和上下卡片重复了状态与按钮，窗口滚动太多。改为桌面应用的连续工作区；资源归属由固定右侧名称确定，模式和记录用页签承载，避免全部内容铺在首页。

日志最小范围：engine/engine.go 记录有配置ID的阶段、启动失败、重连结果和命名清理；connections.go 记录停止来源并提供有界选中配置日志读取；TopSAP session.go 记录分钟采样、累计/增量/末次活动及收发结束上下文；既有托盘窗口接收 WM_POWERBROADCAST 仅记录、不修改休眠或重连策略；gVisor 既有重连日志标注栈归属。保留现有一次认证拒绝和网络重试行为；不添加猜测的心跳或协议兜底。

日志路径及轮转沿用 engineLogs，不创建新的日志服务。 profileId 用 %q 防止换行；UI 读取最近有界的本配置日志并用 textContent 展示，默认不显示其他配置内容。预览仅模拟，不访问真实网关/配置。
