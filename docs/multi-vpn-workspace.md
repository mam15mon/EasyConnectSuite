## 界面与使用

左侧始终保留连接列表，各条 VPN 可独立连接、取消、断开或重试，支持全部/运行中筛选。右侧显示所选连接的状态、时长、虚拟 IP、DNS 和代理地址，资源、设置、运行记录分为三个页签。新建、编辑、删除沿用既有配置和协议字段；切换详情不停止其他连接。运行中的模式/配置不可修改。

日志页显示该配置最近 200 条带 profile ID 的记录，自动刷新间隔 15 秒，也可手动刷新。读较早记录时保持滚动位置。左侧「日志目录」复制完整日志目录。全局系统记录仍从完整日志读取。

最新 v4 修复了连接列表选择：名称、网关、状态和行内空白都能选择对应 VPN；行内连接/断开按钮只执行操作，不改变详情选择。连接时长和状态刷新会复用已有列表节点，不再重建按钮。切换连接后右侧虚拟 IP、内网 DNS、SOCKS5、HTTP 和授权资源会同步到该 profile；未连接或出错配置显示自己的空状态。

完成当前测试后，从托盘退出旧版再启动新包，继续用已有配置连接。关闭窗口继续留在托盘运行；从托盘退出会执行应用停止和清理。新增诊断仅在新包运行后产生，不能补回旧版缺失的停止来源。

## 多 VPN 托盘

右键菜单顶部汇总全体配置的已连接、连接中、重连中、断开中和异常数量。每条配置显示名称、协议、状态，并有独立子菜单：未连接可连接，出错可重试，连接中可取消，已连接/重连中可断开，断开中禁用重复动作。所有已连接项都有勾选，勾选不代表工作台当前选择。

连接/断开命令在菜单打开时捕获 profile ID，之后即使工作台选择或配置顺序改变，也只操作目标配置；没有找到配置时不改用当前配置。只有「查看详情」才切换并打开对应工作台。菜单保留「打开 VPN 工作台」「断开全部 VPN」「退出程序（断开全部）」，全部停止复用原有清理和停止来源日志。

悬浮提示汇总状态并列出运行或出错的配置。提示使用有界 UTF-16 编码，长名称截断不拆分 emoji；配置名中的 & 作为文字显示。图标修改/移除共享锁，窗口销毁通过消息交给创建它的托盘线程。托盘连接失败弹出操作错误，主动取消不作为登录失败提示；取消判断来自本次引擎启动的上下文。

托盘操作日志带 PID、配置 ID 与 action，单条停止仍记录 user_disconnect，全部停止记录 user_disconnect_all，退出记录 app_shutdown。

## 稳定性诊断

完整日志在 `%APPDATA%/VPN/logs/engine.log`，单文件约 8 MiB，保留一份 `engine.log.old`，总量约 16 MiB。所有协议的引擎阶段与清理记录带 PID、引擎编号、配置 ID 和协议；TopSAP 带 PID、配置 ID 和自身会话编号。

- 连接：认证、资源加载、数据 TLS、ACK、进入连接状态，启动失败阶段及原因。
- 停止：单条断开、全部断开、程序退出明确区分；不可恢复的数据通道错误保留原因。
- TopSAP 数据：首次收发的 IPv4 元数据、读写结束原因、累计字节；每分钟采样收发累计/增量、实际采样间隔和距上次收发时间。空闲记录零增量，不据此报错；采样不发网络请求。
- 重连：保活超时和重登录原因、资源更新、进入重连状态；取消导致的预期错误不冒充通道故障。
- 电源与清理：收到 Windows 低功耗进入/恢复通知时记录事件来源与当前连接状态；逐项写出代理、栈、TUN、路由/DNS 等既有清理步骤的结果和耗时。

不记录密码、TOTP 密钥、认证表单、cookie、会话令牌、解密报文或包体。当前实现没有新增协议猜测、认证变体或重连兜底。

用户已确认 fix4 的实际 TopSAP 内网访问成功。新版长时间挂载、真正的机器休眠/恢复、真实 UDP 与多厂商系统 TUN 共存尚未完成实际验证；低功耗通知单元测试不能替代真实休眠测试。TopSAP 协议任务继续保留这部分待验证事项。
